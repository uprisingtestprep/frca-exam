Choose a rehearsal mode

Both modes draw from a real pool of practice content built to the real Primary FRCA OSCE and SOE format. This is self-marked rehearsal, not the real exam.

OSCE Circuit Rehearsal

Draws 16 stations from a 60-station pool and runs a real 5-minute-per-station bell timer, matching the real Primary FRCA OSCE format. Covers resuscitation, technical skills, anatomy, history taking, physical examination, communication skills, anaesthetic/monitoring/measuring equipment, hazards and image interpretation.

SOE Rehearsal

Draws two 30-minute halves from a 60-question pool: 3 pharmacology + 3 physiology/biochemistry questions, then 3 clinical topics (including a critical incident) + 3 physics/clinical measurement/equipment/safety questions, matching the real 12-question Primary FRCA SOE. Self-score each answer using the real 2/1/0 examiner mark scheme.
